## To-Do App Features
- Add tasks (form submit, empty rejected)
- Toggle completed (click task, strikethrough)
- Delete task (hover to reveal ✕)
- Filter: All / Active / Completed
- Stats: "N items left" + Clear Completed
- Delegated single click listener on the `<ul>`
- Uses `textContent` (never `innerHTML`) for user input

## How to run locally
Open `index.html` in a browser. No build step, no dependencies.

- Lesson 9: DOM selection, traversal, content/attribute/style modification, element creation/removal/cloning
